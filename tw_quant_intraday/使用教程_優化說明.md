## 系統概述

tw_quant_intraday 是一套台股量化策略研究系統，包含 4 種交易策略、風險管理模組、回測引擎和 Web 操作介面。系統**僅產出人工委託單**，不會自動連接券商或自動下單。

**本次優化涵蓋三大面向：**
- 策略邏輯強化（新增多重過濾條件、動態停損停利）
- UI 介面全面重設計（更實用的佈局、更清晰的數據呈現）
- 內建使用教程（不需額外文檔即可上手）

## 策略優化說明

### T+1 波段策略 — 優化前後對比

| 項目 | 優化前 | 優化後 |
|------|--------|--------|
| 進場條件 | MA20 + MA60 + 突破 + 量 | MA20 + MA60 + MA排列 + 突破 + 量 + RSI + MACD |
| 停損方式 | 固定 3.5% | ATR×2.0 動態停損 |
| 停利方式 | 固定 7% | ATR×4.0 動態停利 |
| RSI 過濾 | 無 | 45-75 區間（避免追高） |
| MACD 確認 | 無 | 柱狀圖正值或上升 |
| 波動率過濾 | 無 | ATR% 0.5%-6%（排除過冷或過熱標的） |
| 信心度計算 | 固定 0.65 | 多因子動態評分（量比、突破幅度、MACD） |

**新增邏輯說明：**
- **RSI(14) 過濾**：RSI 低於 45 表示趨勢太弱不宜追多；高於 75 表示短期過熱有回檔風險
- **MACD 柱狀圖確認**：要求柱狀圖為正值或正在上升，確認動能方向
- **ATR 動態停損停利**：根據標的實際波動度設定，避免固定百分比造成的過寬或過窄問題
- **MA 排列確認**：快線須在慢線之上，確認趨勢方向

### 開盤區間突破 (ORB) — 優化前後對比

| 項目 | 優化前 | 優化後 |
|------|--------|--------|
| 區間寬度 | 不檢查 | 0.3%-3% 合理區間過濾 |
| 趨勢過濾 | 無 | EMA20 方向確認 |
| 風報比 | 固定 2.0R | 提升至 2.5R |
| 收盤迴避 | 10 分鐘 | 加大至 15 分鐘 |
| 量能確認 | 開盤均量比較 | 突破後 5 根 K 均量 vs 開盤均量 |
| 信心度 | 固定 0.7 | 動態評分（量比+突破幅度） |

**新增邏輯說明：**
- **區間寬度過濾**：過窄的區間容易假突破；過寬表示有重大跳空，不適合 ORB
- **EMA 趨勢確認**：突破方向須與中期趨勢一致，避免逆勢交易
- **收盤迴避加大**：台股收盤前 15 分鐘流動性降低且易有異常波動

### 日內動量策略 — 優化前後對比

| 項目 | 優化前 | 優化後 |
|------|--------|--------|
| 數據要求 | 20 筆 | 30 筆 |
| RSI 過濾 | 無 | 50-80（避免追進過熱區） |
| 量能確認 | 無 | 1.3x 20期均量 |
| 動量持續性 | 僅看 5期報酬 | 5 根中至少 3 根正報酬 |
| 停損 | 固定 1% | ATR×1.5 動態停損 |
| 停利 | 固定 2.5% | ATR×2.5 動態停利 |

### VWAP 均值回歸 — 優化前後對比

| 項目 | 優化前 | 優化後 |
|------|--------|--------|
| 偏離閾值 | 固定 -1.5% | 自適應（2倍日內波動率） |
| 極端偏離 | 不檢查 | 超過 -5% 拒絕（可能為重大事件） |
| 量能確認 | 無 | 1.5x 量能異常（賣壓減緩訊號） |
| 跌勢減速 | 無 | 價格加速度轉正確認 |
| 停利目標 | 100% 回歸 VWAP | 80% 回歸（更實際的目標） |
| 停損 | 固定 1.5% | 動態（取 1.2% 與近期振幅 50% 之較大者） |

## 策略掃描客戶端

### 使用流程

```
┌──────────────┐
│  1. 準備數據   │  ← 到回測頁面下載 TWSE 數據，或手動放入 CSV
└──────┬───────┘
       ▼
┌──────────────┐
│  2. 選擇策略   │  ← T+1 波段 (日線) / 開盤區間突破 (盤中)
└──────┬───────┘
       ▼
┌──────────────┐
│  3. 設定參數   │  ← 股票代號、資金、日期時間
└──────┬───────┘
       ▼
┌──────────────┐
│  4. 執行掃描   │  ← 點擊「執行掃描」按鈕
└──────┬───────┘
       ▼
┌──────────────┐
│  5. 審閱結果   │  ← 查看訊號、風控結果、委託單
└──────┬───────┘
       ▼
┌──────────────┐
│  6. 人工執行   │  ← 帶入券商平台手動下單
└──────────────┘
```

### 各參數說明

| 參數 | 說明 | 建議值 |
|------|------|--------|
| 策略選擇 | T+1 波段使用日線，ORB 使用盤中數據 | 依交易風格選擇 |
| 數據檔案 | 日線 CSV，需包含 OHLCV 欄位 | 使用 Fetch TWSE 下載 |
| 股票代號 | 台股代號（純數字） | 2330, 2317 等 |
| 帳戶資金 | 可用於交易的總資金（TWD） | ≥ 1,000,000 |
| 交易日期 | 模擬的交易日期 | 數據涵蓋的日期 |
| 交易時間 | 盤中時間 (09:00-13:30) | 09:30-13:00 |
| 20日均成交額 | 留空自動計算，或手動輸入 | ≥ 50,000,000 |
| 盤中數據源 | 本地 CSV 或模擬數據 | 本地 CSV (真實數據) |

### 結果解讀

- **BUY + 風控通過** → 可參考委託單資訊手動下單
- **BUY + 風控拒絕** → 策略看多但風控條件不符（如流動性不足、超過日限額等）
- **HOLD** → 目前不符合進場條件，附有具體原因說明

```
       ▼

└──────┬───────┘
       ▼
┌──────────────┐

└──────┬───────┘
       ▼
┌──────────────────────────────────┐
│  5. 分析結果                      │
│  ├─ 權益曲線：觀察資金走勢         │

│  ├─ 進階指標：Sharpe、Sortino      │
│  └─ 交易明細：每筆進出場紀錄       │
└──────────────────────────────────┘
```

### 關鍵指標判讀

| 指標 | 良好 | 尚可 | 需注意 |
|------|------|------|--------|
| 報酬率 | > 5% | 0-5% | < 0% |
| 最大回撤 | > -3% | -3% ~ -8% | < -8% |
| Sharpe | > 1.5 | 0.5-1.5 | < 0.5 |
| 勝率 | > 50% | 40-50% | < 40% |
| Profit Factor | > 1.5 | 1.0-1.5 | < 1.0 |

## UI 優化內容

### 策略掃描頁面

1. **佈局重構**：側邊欄 + 雙欄工作區，左側輸入、右側輸出

4. **價格條**：三色價格條直觀顯示停利/進場/停損的相對位置
5. **內建教程**：Tab 切換至教程頁面，包含完整操作步驟
6. **策略描述**：每種策略附有標籤（當沖/波段/動量/回歸）
7. **風控說明**：清楚列出所有風控規則和閾值
8. **狀態管理**：頂部狀態指示器顯示就緒/執行中/完成/錯誤
9. **響應式設計**：1100px 以下自動堆疊佈局

### 回測分析頁面

1. **權益曲線升級**：帶有漸層填充、Y軸標籤、格線、日期軸
2. **進階指標**：新增 Sharpe、Sortino、Profit Factor、平均獲損等 6 項
3. **交易明細表**：損益欄位帶紅綠色彩，數字使用等寬字體
4. **結果狀態**：成功/失敗使用不同色彩的訊息條
5. **使用說明**：Tab 切換至指標解讀頁面，解釋每個指標的意義
6. **資金建議**：提示建議初始資金和交易單位設定

## 風控機制詳解

系統內建多層風控檢查，所有交易訊號必須通過以下全部條件：

| 規則 | 閾值 | 目的 |
|------|------|------|
| 單筆最大虧損 | ≤ 帳戶 0.8% | 控制單筆風險 |
| 單股部位上限 | ≤ 帳戶 10% | 避免過度集中 |
| 日內成交額上限 | ≤ 帳戶 30% | 控制週轉率 |
| 日內最大虧損 | ≤ 帳戶 2% | 日內停損熔斷 |
| 每日交易次數 | ≤ 6 筆 | 避免過度交易 |
| 連續虧損熔斷 | 連虧 ≤ 3 次 | 防止情緒化交易 |
| 流動性要求 | 20日均成交額 ≥ 5000萬 | 確保可進出場 |
| 開盤迴避 | 開盤後 5 分鐘 | 避開開盤亂序 |
| 收盤迴避 | 收盤前 10 分鐘 | 避開收盤異動 |
| 數據新鮮度 | 延遲 ≤ 60 秒 | 確保數據即時 |
| 漲停板限制 | 不追接近漲停的標的 | 避免鎖漲停風險 |
